# AI for Robotics: offline Practice

Open [the standalone HTML](https://github.com/Debrato2005/Btech_Hons/releases/download/ai-robotics-practice-2026-10-20/ai-for-robotics-mcq.html) directly.
The current application is **Practice only**, with all **5,069 verified questions**.
It needs no server, account, installation or connection.

The production build retains complete solutions, answer IDs, required diagrams,
code snippets, source citations and both original PDFs. It supports course
navigation, search, filters, shuffled single/multiple answers, feedback, bookmarks,
keyboard controls, themes and automatic resume. Existing saved practice answers
and bookmarks remain compatible.

Exams, revision, standalone learning tools and all dashboards are excluded from
the shipped runtime. Their evidence and historical implementations remain in the
repository. [Current scope](docs/CURRENT_SCOPE.md) overrides their old product
requirements in EXECUTION_BRIEF.md.

Read [the measured delivery report](docs/PRACTICE_RELEASE.md) for before/after
memory, browser evidence, source qualifications and build instructions.
Read [recovery instructions](RESUME.md) before rebuilding or changing content.
The release manifest under `delivery/` records current hashes and download URLs.

All 5,069 question objects match the original delivery. Two flagged duplicate
adaptations remain excluded. The current content digest preserves qualified
reuse and source conflicts. The legacy all-course `complete:false` release gate
is separate from acceptance of this tested Practice application.
