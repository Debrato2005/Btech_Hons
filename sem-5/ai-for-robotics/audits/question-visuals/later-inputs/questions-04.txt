• Mamdani’s Inference Method
•
Truncate each output membership function at its 
corresponding membership value, which is 
found from the rule base.
•
Add the remaining truncated membership 
functions with an ‘‘or’’ function in order to 
consolidate them into one area describing the 
output.
•
Calculate the CG of the consolidated area as the 
crisp output value.
Through the process of fuzzification, application of 
the rules base, and defuzzification, an output value 
is calculated that can be applied to the output.
