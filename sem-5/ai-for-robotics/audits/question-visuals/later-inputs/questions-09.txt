The Floor Finder identifies traversable floor regions directly 
from camera images instead of constructing a geometric map. 
•
It assumes that the floor immediately in front of the robot is 
obstacle-free and uses this region as the reference for floor appearance. 
•
Floor detection is based on texture rather than simple color matching, making it 
robust to illumination changes and color variations in indoor environments. 
•
The method characterizes the floor using a combination of hue, saturation, 
luminosity, and roughness to distinguish floor from 
non-floor regions. 
•
By combining these visual attributes, the Floor Finder 
reliably extracts safe traversable areas even under 
shadows or when nearby objects have similar colors to the floor.

3.
Region of Interest (ROI) and Reference Surface Sampling:
– A Region of Interest (ROI) is defined directly in front of the 
robot (red triangle), where immediate foreground is assumed to be obstacle-free. 
– The color and texture features within this region are sampled as a reference model 
of a safe traversable surface for subsequent obstacle detection. 
4.
Mask Generation and Pixel Classification
– Each pixel in far-view region is compared with ROI reference 
using predefined color tolerance thresholds (e.g., ±15 intensity 
levels) and classified as either traversable or non-traversable. 
– The classification results are stored in a binary mask, which is 
subsequently refined using morphological erosion to remove 
isolated noise and strengthen the boundaries of the detected 
safe traversable area.
