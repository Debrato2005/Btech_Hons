AI FOR ROBOTICS: JOIN THE SMALL DOWNLOADS

The single app ZIP is split only for ChatGPT's attachment size limit.
The app itself and its source evidence are unchanged.
All nine parts are needed; do not try to open individual parts.

1. Download part001 through part009 into one new folder.
2. Keep the exact filenames. Remove any browser-added "(1)" suffix from duplicate downloads.
3. Extract join-robotics-tools.zip into that same folder.
   The scripts must sit beside part001 through part009, not inside a nested folder.
4. Run ONE joiner as described below.
5. Wait for SUCCESS and the complete ZIP hash.
6. Extract ai-for-robotics-mcq.zip yourself.
7. Open ai-for-robotics-mcq.html in an existing desktop browser.

WINDOWS POWERSHELL
Open PowerShell in that folder and run:
.\join-robotics.ps1

The script checks every part, creates the ZIP without overwriting an existing file,
and checks the complete ZIP. It does not change security settings or open the app.
If your system policy blocks scripts, do not bypass or change that policy.
Use the Python option only if an existing permitted Python installation is available.

PYTHON ALTERNATIVE (WINDOWS, MAC OR LINUX)
With Python 3.8 or later already installed, run in that folder:
python join-robotics.py
On systems that name Python 3 separately:
python3 join-robotics.py

NO-SCRIPT WINDOWS ALTERNATIVE
If you prefer not to run a downloaded script, Windows Command Prompt can join
these data files directly. Use a new folder with no existing output ZIP.
Run this single line in Command Prompt, not PowerShell:
copy /b /-y "ai-for-robotics-mcq.zip.part001"+"ai-for-robotics-mcq.zip.part002"+"ai-for-robotics-mcq.zip.part003"+"ai-for-robotics-mcq.zip.part004"+"ai-for-robotics-mcq.zip.part005"+"ai-for-robotics-mcq.zip.part006"+"ai-for-robotics-mcq.zip.part007"+"ai-for-robotics-mcq.zip.part008"+"ai-for-robotics-mcq.zip.part009" "ai-for-robotics-mcq.zip"
If asked to overwrite a file, answer N and stop.
Then run:
certutil -hashfile "ai-for-robotics-mcq.zip" SHA256
Compare the result character-for-character with EXPECTED COMPLETE ZIP below.
Do not extract unless it matches. This manual method does not run either script
or alter script/security policies; its full-file hash checks the joined bytes.

IF JOINING STOPS
A missing or changed part is named in the error. Download that part again.
An existing output ZIP is never overwritten. Move it to another folder before retrying.
A sudden power loss can leave an incomplete output ZIP; the joiner will refuse it.
Keep the downloaded parts until you have verified and extracted the complete ZIP.
No installation, account, network access, automatic extraction or app launch is required by either joiner.
